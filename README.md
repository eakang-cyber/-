# DESTINY OS · 운명OS — Phase 1 프로토타입

> 운세를 읽는 시대에서, 내 인생을 탐험하는 시대로.

사주를 읽어 주는 AI 채팅이 아니라, 결정론적 계산 엔진 위에서 **인생 지도 · 관계 비교 · 선택 실험 · 기록**을 직접 조작하는 프리미엄 개인 운명 분석 플랫폼의 첫 번째 동작 프로토타입입니다.

## 실행

```bash
npm install
npm run dev            # http://localhost:3000
npm test               # 엔진·해석·상담·추천 단위 테스트(46건)
npm run build && npm start
BASE_URL=http://localhost:3000 node tests/e2e/smoke.cjs     # E2E 스모크(15건, Playwright)
BASE_URL=http://localhost:3000 node tests/e2e/counsel.cjs   # 고민상담소 흐름(18건)
npm run build && npm run build:artifact                    # dist/destiny-os.html 단일 파일 미리보기
```

Node 20+ · Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · lunar-javascript(MIT).

## 구조

```
src/engine/     결정론적 계산(원국·절기·시간대·진태양시·자시·대운·합충형) — AI 미사용
src/rules/      전통 규칙 레지스트리(rule_id) · 해설 문안 · 규칙 적용기 · 조사 처리
src/content/    샘플 데이터(가상의 예시 인물, 데모 상대, 예시 기록)
src/state/      앱 상태(기본: 메모리 전용 / 선택: 탭 임시 보관) — 서버 전송 없음
src/ui/         디자인 시스템 컴포넌트 · 차트 · 앱 셸 · 라우터
src/screens/    11개 화면
src/app/        Next.js App Router, /api/chart 서버 계산 API
tests/          단위 테스트(vitest) · E2E 스모크(Playwright)
docs/           설계 문서
```

## Phase 1 자체 점검

| 질문 | 답 | 근거 |
|---|---|---|
| 모바일에서 사용하기 편한가? | 예 | 390px에서 가로 넘침 0, 하단 탭 5개·하단 고정 입력 버튼, 터치 영역 36px 이상 |
| 첫 화면 10초 안에 가치를 이해하는가? | 대체로 예 | 헤드라인 + 실제 계산된 인생 지도 미리보기가 첫 화면에 있음. 사용자 테스트로 확인 필요 |
| 무료만으로 흥미로운가? | 예 | 캐릭터 전체, 10년 흐름 전체, 모든 해의 주제, 올해 ±1년 상세, 일·돈 5문항, 관계 기본 |
| 유료가 글자 수만 늘린 것인가? | 아니오 | 유료는 91개 해 상세 탐색, 관심사 전환, 대화 스크립트, 가중 비교 도구, 개인화 질문, 저장 기능 |
| ChatGPT보다 편리한가? | 예 | 질문 작성 불필요, 같은 결과 재현, 시각 탐색, 기록 누적 |
| 해석 근거를 추적할 수 있는가? | 예 | 모든 해석 카드에 rule_id·계산 근거·다른 해석·검수 상태. 원문 위치는 "검수 전"으로 정직하게 표시 |
| 모든 버튼이 작동하는가? | 예 | E2E 13건 통과, 미구현(이미지 저장)은 비활성 + "준비 중" |
| 데모 데이터와 실제 계산을 구분했는가? | 예 | `계산`·`미검증`·`샘플`·`예시`·`데모` 배지, 샘플 사용자 배너 |
