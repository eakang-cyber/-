# 07. 고민상담소 설계 — 사주로 답하는 참여형 상담

> 고객이 **자기 상황을 직접 쓰고**, 몇 가지를 **탭으로 답하면**, 내 사주의 구조와 시기 흐름에 비춘 **상담지**를 받는다.
> 챗봇 대화창이 아니라 "상담지(문서)"이며, 결정은 고객이 한다.

## 1. 왜 이 기능인가
- 운세 사이트는 "내가 궁금한 것"을 물을 곳이 없고, ChatGPT는 물을 수는 있지만 계산이 불안정하고 사주와 현실 조언이 뒤섞인다.
- 고객이 돈을 내는 순간은 **내 문제에 대한 답**이 필요할 때다(이직, 부동산, 동업, 연애, 가족). 고민 1건 단위 상품은 9,900원 성향 리포트보다 객단가를 올릴 수 있다.

## 2. 흐름 (화면 `#ask`, 진입: 랜딩 고민 입력창 · 하단 첫 번째 탭)

| 단계 | 고객이 하는 일 | 설계 장치 |
|---|---|---|
| 1 고민 적기 | 600자 이내로 자유롭게 작성 | 예시 문장 5개, "개인정보 적지 마세요", 브라우저 밖 전송 없음 |
| 2 몇 가지만 | 분야(자동 추정·수정 가능) · 마감 · 지금 마음 · 가장 걸리는 것 · 선택지 A/B(선택) | 모두 한 번 탭. 고객이 '참여'하는 느낌과 답변의 재료를 동시에 만든다 |
| 생년월일 | 예시 인물로 보는 중이면 "내 사주로 상담받기" | 입력 후 **고민 그대로 상담소로 복귀**(returnTo) |
| 3 상담지 | 읽고, 근거를 펼쳐 봄 | 아래 7개 섹션 |
| 4 반응 | 맞아요 / 일부만 / 달라요 + 한 줄 | 아카이브 '질문'으로 저장 → 나중에 결과를 이어 적는 재방문 동기 |
| 5 심층 상담(유료) | 모의 결제 | AI 상담사 풀이 · 추가 질문 3번 · 결정 리포트 |

## 3. 상담지 구조 (무료로 완결)

1. **이렇게 이해했어요** — 고객의 문장을 그대로 인용 + 탭 답변 요약 (내 이야기라는 느낌)
2. **이 고민 앞의 나** `전통 해석` — 고민 분야와 관련된 십성 주제군이 내 원국에 몇 곳 있는지(익숙함 / 한 곳 / 드러나지 않음), 관계형 고민이면 '가까운 관계 자리'의 합·충
3. **시기의 흐름** `전통 해석` — 지금 10년·올해 주제 + 앞으로 12개월 중 이 고민의 주제가 드러나는 달(월운). "언제 하라"가 아니라 "언제 다시 들여다볼지"
4. **지금 마음에 대해** `현실 조언` — 마음·걸리는 것에 맞춘 문장, 선택지가 있으면 '후회 비교' 질문
5. **사주보다 먼저 확인할 것** `현실 조언` — 분야별 3개, 공식 확인처 링크(토지이음·실거래가·팩토리온·고용24·파인 등)
6. **이번 주 작은 실험** + 스스로에게 묻는 질문 3개
7. **반응 버튼**

| 고민 분야 | 관련 주제군(전통 의미) | 결정 리포트 연결 |
|---|---|---|
| 일·커리어 | 표현과 생산 · 책임과 규칙 | 이직·퇴사 |
| 돈·투자 | 현실과 성과 · 나와 동료 | 큰돈 투자·대출 |
| 부동산·사업장 | 현실과 성과 · 배움과 보호(문서) | 부동산·부지 매입 |
| 사업·창업 | 표현과 생산 · 현실과 성과 | 창업·사업 확장 |
| 연애·결혼 | 성별에 따른 상대 주제(전통) + 가까운 관계 자리 | — (관계 시뮬레이터) |
| 가족 | 배움과 보호 · 나와 동료 | — |
| 인간관계 | 나와 동료 · 책임과 규칙 | — |
| 나·진로 | 배움과 보호 · 표현과 생산 | — |

## 4. 유료: 심층 상담 (고민 1건)
- **AI 상담사 풀이**: Claude가 "고객의 고민 글 + 상담지의 근거 블록"만 받아 다시 씀. 사주 계산은 하지 않음.
  - 출력 JSON 5필드(공감 요약 · 전통 해석 · 시기 · 현실 한 걸음 · 질문)
  - 자동 검사: 한자, 금지어(사망·파산·이혼·확률·반드시·전문 용어), 빈 필드 → 실패 시 표시하지 않음
  - 이름·생년월일은 보내지 않음(테스트로 보장)
  - 아티팩트에서는 뷰어 본인의 Claude 계정으로 실행(첫 사용 시 허락 요청), 사용 불가 환경에선 안내 후 무료 상담지 유지
- **추가 질문 3번**: 같은 근거·규칙으로 3~5문장 답변
- **결정 리포트**(`#decide`, 결정형 고민): 24개월 단계별 흐름(조사→협상→인허가→계약→실행의 주제가 맞물리는 달), 후보 A·B 비교(고객이 매긴 점수), 확인 목록 전체, 질문 10개, 결정 일지

## 5. 지켜야 할 선
- "사세요/사지 마세요", "헤어지세요", 특정 달 계약 권유 금지 — 단계와 주제가 **겹치는 달**까지만 말함(`DEC-PHASE-001`, 편집 해설임을 명시)
- "어디가 맞나"에는 정직하게 답함: 사주로 특정 지역·부지를 고를 근거 없음, 방위론은 검수 전이라 큰돈 결정에 쓰지 않음
- 실제 '시즌'은 금리·정책자금 공고·매물·인허가 기간이 정한다고 명시

## 6. 돈이 되는지 확인하는 장치 (베타)
- **가격 테스트**: 심층 상담 가격을 방문자마다 19,900 / 29,000 / 39,000원 중 무작위 표시
- 자동 신호: 표시 가격, 모의 결제 클릭 여부, 고민 분야, 상담지 반응, 내 생년월일 입력 여부 (고민 글 내용은 수집하지 않음)
- 피드백 질문: "고민 1건 심층 상담이라면 얼마까지?"
- 판단 기준(가설): 상담지 "맞아요+일부만" 60% 이상, 심층 상담 모의 결제 클릭 10% 이상, 가격별 클릭률 차이로 적정가 추정

## 7. Phase 3 전환 시
- AI 호출을 서버 어댑터(Claude API)로 이전, 고민 글은 암호화 저장·기본 30일 보관·삭제 가능
- 고민 분야 자동 분류를 AI로 교체(현재 키워드 매칭)
- 3·6·12개월 뒤 "그 고민 어떻게 됐나요?" 알림 → 결정 일지 회고(재방문)
- 위기 신호(자해·극단적 표현) 감지 시 상담 대신 전문 기관 안내로 전환 — **정식 출시 전 필수**
