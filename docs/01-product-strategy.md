# 01. 제품 전략 · 화면 구조 · 사용자 여정 · 유료 상품 · 로드맵

## 1. 기존 AI 사주 채팅보다 나은 이유

| 관점 | ChatGPT에 생년월일 입력 | 운명OS |
|---|---|---|
| 계산 | 언어모델이 여덟 글자를 '추측'함. 절기·시간대·자시 기준이 매번 달라질 수 있음 | 결정론적 엔진이 계산. 같은 입력 + 같은 규칙 버전 = 같은 결과(테스트로 보장) |
| 근거 | 출처 없는 문장, 그럴듯한 고전 인용이 섞일 위험 | 모든 해석 블록에 `rule_id`, 계산 근거, 다른 해석, 검수 상태를 붙임. 원문 위치는 검수 전이면 "검수 전"으로 표시 |
| 형태 | 긴 텍스트. 좋은 답을 얻으려면 질문을 잘 써야 함 | 0~90세 지도, 두 사람 비교, 선택지 비교 등 직접 조작하는 화면 |
| 시간 | 대화가 끝나면 사라짐 | 사건·목표·회고를 기록해 그해 해석과 나란히 다시 봄(재방문 동기) |
| 안전 | 예언·불안 유도 문장이 섞이기 쉬움 | 금지 표현 테스트, 점수·확률·위험한 해 표시 금지 정책 |

## 2. 고객이 9,900원을 낼 이유

1. **무료가 이미 완결된 이야기**라서 신뢰가 생긴 뒤에 결제를 제안한다(가리기식 유도 없음).
2. 유료는 **글자 수가 아니라 기능**이다: 91개 해 전체 상세, 관심사 5종 전환, 갈등 상황별 대화 스크립트, 내가 매긴 기준으로 선택지 가중 비교, 개인화 질문 3개, 리포트 저장.
3. **한 번 사면 계속 쓰는 도구**다: 아카이브에 기록이 쌓일수록 리포트의 가치가 올라간다.
4. 가격·포함 항목·환불 조건을 결제 전에 모두 보여 준다.

## 3. 가장 중요한 3개 화면

1. **0~90세 인생 지도(화면 D)** — 대표 기능. 10년 띠 + 91칸 연도 리본 + 나이 슬라이더 + 내 기록 나란히 보기.
2. **나의 인생 캐릭터(화면 C)** — 첫 10초의 호기심과 공유가 시작되는 곳. 핵심 문장 + 세 이야기 + 근거 펼쳐보기.
3. **인생 아카이브(화면 I)** — 재방문 이유. 기록, 회고, 과거의 나와 현재의 나 비교, 내보내기·삭제.

## 4. MVP와 추후 기능

| 구분 | MVP(Phase 1~3) | 추후 |
|---|---|---|
| 계산 | 양력·음력·윤달, 절기 월주, 일·시주, 경도/진태양시, 자시 정책, 역사적 시간대, 대운 | 해외 출생(세계 시간대·좌표 DB), 신강/신약·용신(검수 후), 신살 |
| 해석 | 규칙 15종(초안) + 해설 문안 | 학파별 해석 토글, 명리 검수자 승인 규칙 100종+, Claude 설명자 |
| 화면 | 9개 핵심 + 리포트 + 계산 기준 | 월운, 알림(생일·대운 교체), 공유 이미지 생성 |
| 관계 | 1:1 비교, 동의 체크 | 상대방이 직접 입력하는 초대 링크(제3자 정보 수집 최소화) |
| 계정 | 이메일·카카오·애플 로그인, 리포트 저장 | 가족 계정, 기록 내보내기 자동화 |
| 결제 | 단건 9,900원(Toss Payments) | 연간 회고 패키지, 관계 리포트 단품 |

## 5. 전체 화면 구조 (IA)

```
랜딩(#)                          ─ 가치 제안 · 인생 지도 미리보기 · 무료 범위 · 실제 리포트 샘플 · 개인정보 · 한계
└ 출생정보 입력(#start)          ─ 6단계: 이름/보관방식 → 날짜(양·음·윤달) → 시간(모름) → 도시 → 성별·계산기준 → 확인·미리보기
  └ 앱 셸 (모바일 하단 탭 5 + 메뉴 / 데스크톱 좌측 내비)
     ├ 나(#me)                   ─ 화면 C 인생 캐릭터
     ├ 인생 지도(#map)           ─ 화면 D
     ├ 일·돈(#work)              ─ 화면 E
     ├ 관계(#relation)           ─ 화면 F
     ├ 실험실(#lab)              ─ 화면 G
     ├ 아카이브(#archive)        ─ 화면 I
     ├ 마스터 리포트(#report)    ─ 8개 챕터(데모 프리미엄)
     │  └ 구매(#premium)         ─ 화면 H 모의 결제
     └ 계산 기준과 근거(#method) ─ 정책 전환 · 검증 상태 · 규칙 레지스트리
```

## 6. 사용자 여정

| 단계 | 사용자의 마음 | 화면 | 설계 장치 |
|---|---|---|---|
| 발견 | "또 운세 사이트?" | 랜딩 | 첫 화면에 실제 계산된 인생 지도 미리보기, 점수·예언 없음 명시 |
| 시작 | "개인정보 괜찮나?" | 입력 1단계 | 닉네임 허용, '저장하지 않고 체험' 기본, 서버 전송 없음 |
| 첫 결과 | "내 얘기 같은데?" | 캐릭터 | 핵심 문장 → 세 이야기 탭 → 근거 펼쳐보기 → 스스로에게 묻기 |
| 탐험 | "그럼 나는 언제?" | 인생 지도 | 지금 위치 표시, 올해 ±1년 상세, 모든 해 주제 색 |
| 적용 | "그래서 뭘 하라고?" | 일·돈 / 실험실 | 전통 해석과 현실 조언 분리, 확인 체크리스트 |
| 공유 | "친구랑 비교" | 관계 | 동의 체크 후 비교, 점수 없음, 대화 질문 |
| 결제 | "더 보고 싶다" | 프리미엄 | 무료 vs 리포트 비교표, 환불 조건, 모의 결제 |
| 재방문 | "올해 어땠지?" | 아카이브 | 사건·목표·회고 기록, 과거/현재 비교, 내보내기·삭제 |

## 7. 유료 상품 구조

- **인생 마스터 리포트 9,900원** (VAT 포함, 1회 결제, 구독 아님)
  - 전체 인생 지도(0~90세 연도별) · 돈과 일 심층(관심사 5종) · 관계 심층(갈등 상황별 대화) · 10년 연도별 해석 · 선택 실험실 확장 · 개인화 질문 3개 · 저장/다시 보기
- **환불(초안, 법률 검토 필요)**: 결제 후 7일 이내·미열람 전액 환불 / 열람 후 디지털 콘텐츠 특성상 제한 가능 / 계산 오류 확인 시 전액 환불.
- **검증 지표**: 무료→결제 전환율, 결제자 만족도(리포트 후 1문항), 30일 재방문율, 아카이브 기록 수, 환불률.
- **매출 목표 산식(가설)**: 연 100억 원 ≈ 9,900원 × 약 101만 건. 단건만으로는 무리하므로, Phase 4 이후 관계 리포트·연간 회고·선물하기로 객단가와 재구매를 검증한다. **목표는 설계 기준일 뿐 보장된 성과가 아니다.**

## 8. 상용화 로드맵

| Phase | 기간(가정) | 산출물 | 통과 기준 |
|---|---|---|---|
| 1 프로토타입 | 완료 | 이 저장소: 11개 화면, 엔진 v0.3, 규칙 15종 초안, 테스트 24+13건 | 내부 사용성 점검, 5명 이상 사용자 인터뷰 |
